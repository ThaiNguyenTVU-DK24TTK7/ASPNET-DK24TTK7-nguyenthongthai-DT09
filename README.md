# TechStore - Website bán laptop

## 1. Giới thiệu

TechStore là website thương mại điện tử hỗ trợ kinh doanh laptop trực tuyến.
Hệ thống cung cấp các chức năng cho khách hàng và quản trị viên như xem sản phẩm,
tìm kiếm, quản lý giỏ hàng, đặt hàng, thanh toán và quản lý sản phẩm.

## 2. Công nghệ sử dụng

- ASP.NET Core MVC
- C#
- Entity Framework Core
- SQL Server
- HTML/CSS/JavaScript
- Bootstrap

## 3. Cấu trúc repository

- `scr/` - Mã nguồn của hệ thống
- `setup/` - Tài liệu cài đặt và cơ sở dữ liệu
- `progress-report/` - Báo cáo tiến độ theo tuần
- `thesis/` - Tài liệu khóa luận
- `soft/` - Phần mềm liên quan
- `docker/` - Tệp triển khai Docker

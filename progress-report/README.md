# Báo cáo tiến độ

Thư mục lưu báo cáo tiến độ thực hiện dự án theo từng tuần.

## Tuần 1 (06/09/2026 - 13/09/2026)

- Tìm hiểu nhu cầu mua sắm trực tuyến và chọn đề tài xây dựng website bán laptop TechStore.
- Xác định mục tiêu, đối tượng, phạm vi nghiên cứu và các chức năng chính của hệ thống.
- Khảo sát thực trạng mua bán laptop và đề xuất giải pháp quản lý sản phẩm, đơn hàng tập trung trên website.
- Nghiên cứu mô hình MVC, ASP.NET Core, SQL Server, HTML/CSS/JavaScript/Bootstrap và các sơ đồ UML.
- Cài đặt và kiểm tra môi trường phát triển: .NET 8, SQL Server, SSMS và Visual Studio/Visual Studio Code.

## Tuần 2 (14/09/2026 - 20/09/2026)

- Tạo repository GitHub cho dự án và thiết lập thành viên/collaborator.
- Khởi tạo solution và project ASP.NET Core MVC.
- Phân tích các đối tượng dữ liệu chính như sản phẩm, danh mục, người dùng, giỏ hàng và đơn hàng.
- Thiết kế cơ sở dữ liệu ban đầu và cấu hình kết nối SQL Server bằng Entity Framework Core.
- Dựng cấu trúc thư mục, model, controller và các giao diện cơ bản cho hệ thống.
